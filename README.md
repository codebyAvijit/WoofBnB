# 🐶 WoofBnB

> **Find trusted pet sitters near you.**

WoofBnB is a location-based marketplace platform that connects pet owners with verified nearby pet sitters. Inspired by the simplicity of **Airbnb**, the real-time location experience of **Uber**, and the mapping capabilities of **Google Maps**, WoofBnB helps users discover reliable pet care services based on their current location or a searched city.

This project is being developed as a **portfolio project** following an enterprise software development workflow, from business analysis and architecture through AI-assisted implementation and deployment.

## Clone the Repository

```bash

```

## Install Dependencies

### Frontend

```bash
cd client

npm install
```

### Backend

```bash
cd server

npm install
```
